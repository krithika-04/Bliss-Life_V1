**Bliss Life** is a dynamic blogging platform where users can share their thoughts, experiences, and stories through blog posts. Users can create, edit, and delete their posts, as well as explore and engage with content from others. Bliss Life provides a space for self-expression and connection with a community of like-minded individuals.

![bs-view](https://github.com/user-attachments/assets/f8761f6f-560e-4924-aa31-925a52c2f38a)

## Key Features

- **Create Blog Posts**: Users can easily create new blog posts, complete with images and formatted content, to share their thoughts and experiences.

   ![bs-create-post](https://github.com/user-attachments/assets/02aad032-b461-4a95-9182-34bcba9b6406)

- **Edit and Manage Posts**: Users can edit their existing posts, allowing them to update or refine their content as needed.

   ![bs-edit](https://github.com/user-attachments/assets/58cf52b7-c76d-4c3c-8e35-c3b1366b9486)

- **Delete Posts**: If a post is no longer relevant or desired, users have the option to delete it from their profile.

  ![bs-editdel](https://github.com/user-attachments/assets/24c851fb-5478-47f6-8548-a62fec3db0d6)

- **Explore Others' Posts**: Discover and engage with posts from other users, creating a vibrant community of bloggers.

  ![bs-view](https://github.com/user-attachments/assets/e62bdd0e-4936-4ccc-a955-a53144320666)

- **User Profiles**: Each user has a personalized profile where they can manage their blog posts and interact with others.

 ![bs-profile](https://github.com/user-attachments/assets/c59f7cf4-6a92-4607-ba4f-39f7b58ed825)


- **Responsive Design**: Bliss Life is designed to be user-friendly and accessible on various devices, providing a seamless experience across desktops, tablets, and mobile phones.

## Technologies Used

- **Node.js**: Server-side runtime environment for building and running the application's backend.

- **Express**: Web application framework for Node.js, used to handle routing and middleware.

- **MongoDB**: NoSQL database for storing and managing user data and blog posts.

- **Vue.js**: JavaScript framework for building the interactive and dynamic user interface of the application.
